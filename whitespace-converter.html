␣空白換行轉換器

在空格與空行中插入零寬度空格，讓 Facebook、Instagram、Threads 等社群貼文保留連續空白、段落留白與縮排排版

模式：
0
結果字元數
0
零寬度空格數
0
行數

使用步驟

  1. 在左側輸入或貼上你的文字。
  2. 右側會即時產生結果，按「複製」。
  3. 貼到 Facebook、Instagram、Threads 或 WordPress 貼文即可。

原理與說明

  • 社群平台通常會把「連續空格」與「空行」自動壓縮成一個，讓排版失效。
  • 本工具會在空格與空行之間插入「零寬度空格（U+200B）」，肉眼看不見、佔位卻不會被壓縮，因此排版得以保留。
  • 可做出：單字間更多空格、段落間更多留白、句首縮排等效果。
  • 切換「還原」模式可移除文字中的零寬度空格，復原成乾淨文字。
  • 所有處理都在瀏覽器本機完成，文字不會上傳。
